# Life Dashboard — Design Guide

## Design Context

### Users
A single creator/owner (Sean), personal use. Primary context: **daily, especially morning** — a quick "AI-powered morning glance." Jobs to be done: see readiness/schedule/top-reads at a glance, capture a task, reflect in the evening. This is a calm personal-intelligence ritual + sanctuary, not a multi-tenant work tool.

### Brand Personality
**Serene · crafted · characterful.** A painterly personal sanctuary with a retro soul. It should feel calm and made-with-care — the opposite of a generic SaaS dashboard. Delight comes from craft, not noise.

### Aesthetic Direction
**Refined retro** (ratified 2026-06-07). A lush, painterly **pixel-art Monet pond** backdrop (KEPT — it's the soul) with a crisp **pixel / neo-brutalist UI system** layered on top:
- **Solid colour fills** (no translucent "glass" surfaces), **thick 2–3px borders**, **hard offset (pixel) shadows** (no blur), **squarer corners**, `image-rendering: pixelated`.
- **VT323** pixel font for headings/chrome; **Space Grotesk** for body (kept legible).
- Both **light + dark**, driven by time-of-day (morning/noon/twilight/night).
- **References:** Monet-meets-8-bit; cozy-but-crisp pixel craft. **Anti-references:** generic AI dashboards (translucent glass cards, soft blurry shadows, gradient text, cyan-on-dark glow), corporate/sterile flat UI.

### Design Principles
1. **Pixel UI as a SYSTEM, not a gimmick.** Shared primitives (Card / Button / Input / Nav / Chip) all speak the pixel language: solid fill, thick border, hard offset shadow, squarer corners. Scales site-wide.
2. **Solid colour, principled.** 60-30-10 (dominant surface / secondary / **scarce** accent). Primitive → semantic → component tokens from the existing hues (sky / bloom / pond / ember / lilac / neutral). **No translucent overlay fills** for surfaces.
3. **WCAG AA, both modes.** Every text/UI pair ≥ 4.5:1 (text) / 3:1 (UI), validated light + dark. Pixel-art is harder for a11y → **body text stays legible** (Space Grotesk; pixel font for headings/chrome only); decorative sprites `aria-hidden`; reduced-motion respected.
4. **Keep the pond lush.** The painterly scene is the soul — harden only the UI on top. Backdrop = atmosphere; UI = crisp legible structure.
5. **Characterful restraint.** Committed retro craft, but legible + usable first. Charm via intentional detail (hard pixel shadows, pixel corners/frames, VT323), never visual noise.
